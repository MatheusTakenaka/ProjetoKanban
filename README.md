# 📌 Projeto Kanban

Sistema de organização de tarefas no estilo Kanban.


# 📌 Funcionalidades

- Organização de tarefas


# 🚀 Tecnologias utilizadas

Este projeto foi desenvolvido com:

- HTML
- CSS
- JavaScript
- Claude Code (IA auxiliar no desenvolvimento)

  
# 🤖 IA utilizada

Este projeto contou com o auxílio da IA Claude Code para apoio no desenvolvimento, estruturação e implementação de funcionalidades.

# ▶️ Como executar o projeto

## Clone o repositório

```bash
git clone https://github.com/SEU-USUARIO/ProjetoKanban.git
```

## Entre na pasta do projeto

```bash
cd ProjetoKanban
```

## Instale as dependências

```bash
npm install
```
